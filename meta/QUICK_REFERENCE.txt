INITIALIZATION SEQUENCE
=======================

1. init.lua (main entry point, calls require("core"))
2. core/init.lua starts:
   a) core/global.lua         - OS detection and paths
   b) core/options.lua        - Editor defaults
   c) core/event.lua          - Autocmd setup
   d) core/pack.lua           - Plugin loading
   e) keymap/init.lua         - Keybindings
3. core/settings.lua applied
4. User customizations merged (if present)

KEY INTEGRATION POINTS
======================

How initialization flows:
  nvim startup → init.lua → require("core") → core/init.lua → other modules

How plugins are specified:
  1. Plugin defined in modules/plugins/{category}.lua
  2. Plugin listed in lazy.nvim array
  3. Config file referenced via config = require("...")
  4. Config file in modules/configs/{category}/{name}.lua

How user customization works:
  1. User file in lua/user/ mirrors lua/modules/ structure
  2. System automatically merges user settings with defaults
  3. No need to modify core files

How keybindings are defined:
  map_cr("command"):with_silent():with_noremap():with_desc("help text")
  Uses builder pattern for chainable, readable syntax

How utilities are shared:
  - modules/utils/init.lua provides palette, highlights, plugin loading
  - Functions used throughout the configuration
  - Easy to extend for custom utilities


CUSTOMIZATION QUICK HELP
=========================

To add a new plugin:
  1. Edit modules/plugins/{category}.lua (add to list)
  2. Create modules/configs/{category}/{name}.lua
  3. Run :Lazy sync in Neovim

To override a setting:
  1. Edit user/settings.lua (define override)
  2. Changes automatically merged with defaults

To override a keybinding:
  1. Edit user/keymap/{category}.lua
  2. Use same map_* functions as core keybindings

To disable a plugin:
  1. Add to settings.disabled_plugins list
  2. Run :Lazy sync

To add language support:
  1. Add LSP to core/settings.lua lsp_deps
  2. Create user/configs/lang/{language}.lua
  3. Add plugin spec in user/plugins/lang.lua

TROUBLESHOOTING QUICK REFERENCE
================================

Plugin not loading:
  - Check modules/plugins/{category}.lua for plugin definition
  - Check lazy loading conditions (event/cmd/cond)
  - Run :Lazy debug to see loading status

Config not applied:
  - Check modules/configs/{category}/{name}.lua exists
  - Verify config = require("...") path is correct
  - Check for syntax errors

Keybinding not working:
  - Check keymap/{category}.lua or user/keymap/{category}.lua
  - Verify map syntax is correct
  - Check for conflicting keybindings

Startup time slow:
  - Run :Lazy profile
  - Check for large files or plugins with no lazy condition
  - Review core/pack.lua performance settings
